# SkyRaid

Arena shooter for up to 8 players. Unity 6000.3.11f1, Photon Fusion 2.1.1 (server mode: `GameMode.Server`). Windows clients.

The Fusion SDK isn't in this copy (`Assets/Photon/Fusion/` only holds the settings files, trimmed). The scenes are described in `Assets/SkyRaid/Scenes/SCENES.README.txt`. The Fusion App ID was removed from this copy.

Dedicated servers run on Edgegap. See EDGEGAP-NOTES.md.
