# BR200 project (eval copy)

Photon's BR200 Battle Royale sample, version 2.1.0, imported unchanged into Unity 6000.3.11f1 on Windows. Fusion 2.1.1 build 2177.

This copy has no BR200 or Photon Fusion files: they are licensed, so `Assets/TPSBR/` and `Assets/Photon/Fusion/` only hold notes and the two Fusion settings files, trimmed to the keys that matter here. `ProjectSettings/ProjectSettings.asset` is trimmed the same way. The Fusion App ID was removed from this copy; the real project has one.

`Packages/manifest.json` lists only the main packages.

Nothing has been done for dedicated servers yet. The game runs in the editor and players can host from the Menu.
