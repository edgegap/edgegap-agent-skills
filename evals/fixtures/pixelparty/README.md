# Pixel Party

Browser party game, 3-8 players, 60-second tap-the-color rounds. Godot 4.7 (Compatibility renderer), WebSocketMultiplayerPeer.
Published on itch.io as an HTML5 build (https://pixelparty-team.itch.io/pixel-party). Today one player hosts from the desktop build
and the others paste `ws://<host ip>:8910` into the Join box, which doesn't work from itch (https page) and needs port forwarding.

Exports: Web (itch.io) and Windows. The presets use an explicit file list to keep the web download small.
